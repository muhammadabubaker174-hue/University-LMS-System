Topic : University LMS System

Purpose :
A University Learning Management System (LMS) is a Web based Application that helps students at tracking their Grades, Timetable, Course Enrollment and other activities, It also helps Teachers in storing the assignment and quiz marks and marking the attendance at the Lms.
The Admin Manages the whole system like giving access to particular person only.
Users :
•	Students 
•	Teacher 
•	Administrators
Stakeholders :
•	Students
•	Teachers
•	Administrators
•	University
•	Non-Teaching Faculty
Functional Requirement :
•	Admin can add , remove or edit the accounts for users .
•	Students can enroll in different courses provided by the administration.
•	Admin can decide who is a student, teacher or TA and what they can do.
•	Teacher can mark attendance directly in the lms which is managed by admin.
•	Teacher can upload Assignment marks, Quizzes Marks , Mid and final Assessments.
•	Admin can calculates and display Grades on the student portal
•	Student can Check their Grades once it is uploaded.
•	Admin can check class stats like how many students are enrolled in a course and how many courses are live for enrollment.
Non-Functional Requirement :
•	The system should work at same speed when the No.of Students using their accounts at the same time
•	The system should be available for all the Students and Teacher all the time 
•	The UI should be clean , easy to understand, and impressive for everyone.
•	The Backup of data should be saved also in case of data losses.
•	Only the Right people can see their data like student can check their grades only.
•	 The error handling should be very great it completely gives a clear message in case of errors.
•	Pages and materials should open quickly, even with slow internet.

Risks :
•	Server crash if load increases
•	Access to unauthorized person
•	Data Loss
•	Lost works due to Bugs
Quality Attributes :
•	Maintailabity i.e The code should be maintailable enough that we can add more functionality if needed.
•	Reliability i.e the system consistently performs its functions without failure, especially for grading and submissions
•	Clean UI i.e the clean interface is used for all kind of users 

Where AI could be used :
•	Automated grading like every student marks are used to calculate their grade and gpa.
•	Chatbot for answering the repetitive queries of students.
•	Analysis of students previous grades and predict the future courses on engagement patterns.
•	Ai can suggest different resources to a student enrolled in a course.

What could go wrong if AI is used incorrectly?
•	If the AI model is trained on uncertain data, it could give favour to certain students which is disadvantage for others.
•	AI systems analyzing student behavior or performance data could be misused or leaked if it is not properly secured.
